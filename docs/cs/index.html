CSDictKeyIterator

Iterates a dictionary's keys with a typed enumerator, so value types aren't boxed. Its methods are inline, so a for loop over it compiles to a plain loop.

CSDictKeyValueIterator

Iterates a dictionary's entries in one pass over its KeyValuePairs. Its methods are inline, so a for (key => value in map) loop compiles to a plain loop without building an object per entry.

CSDictValueIterator

Iterates a dictionary's values with a typed enumerator, so value types aren't boxed. Its methods are inline, so a for loop over it compiles to a plain loop.

CSEnumeratorIterator

Adapts a C# IEnumerator<T> to the Haxe iterator protocol.

CSListIterator

Iterates a List<T> by index, so value types aren't boxed. Its methods are inline, so a for loop over it compiles to a plain indexed loop.
