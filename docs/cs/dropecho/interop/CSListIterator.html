class CSListIterator<V>

package dropecho.interop

import dropecho.interop.AbstractArray

@:nativeGen@:nativeGen

Iterates a List<T> by index, so value types aren't boxed. Its methods are inline, so a for loop over it compiles to a plain indexed loop.
