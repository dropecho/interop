class EnumSet<T>

package dropecho.interop.set

The JS backing of AbstractSet for enum items. Items compare by value, so Floor(1) matches any other Floor(1). With a key function, items with the same key count as the same item instead.

Constructor

new(?key:Func_1<T, Int>)

Creates an empty set.

Parameters:

key

Gives the key that identifies an item, such as its index or id. Without one, items compare by value.

Methods

Parameters:

item

The item to add.

Returns:

True when the item was added, false when an equal item was already there.
