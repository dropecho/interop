abstract EnumKeyMap<K, V>(EnumValueMap<K, V>)

package dropecho.interop.map

from EnumValueMap<K, V>, to EnumValueMap<K, V>

@:forward(exists,remove,clear,keys,iterator,keyValueIterator,toString)

The JS backing of AbstractMap for enum keys. It is a Haxe EnumValueMap, so keys compare by value (Floor(1) matches any other Floor(1)) and come back as enum values. It is not a plain JS object.
