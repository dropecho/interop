dropecho.interop API (JS)

dropecho.interop.map

..
EnumKeyMap

The JS backing of AbstractMap for enum keys. It is a Haxe EnumValueMap, so keys compare by value (Floor(1) matches any other Floor(1)) and come back as enum values. It is not a plain JS object.

IdentityKeyMap

The JS backing of AbstractMap for object, function and Bool keys. It is a native JS Map: objects are compared by identity, so two instances with equal fields are different keys, matching a C# Dictionary. Entries iterate in insertion order.

NumberKeyIterator

Iterates a plain object's keys as numbers.

NumberKeyMap

The JS backing of AbstractMap for Int and Float keys. It is a plain JS object like StringKeyMap, but keys come back as numbers when iterated. JS lists number-like keys in ascending order, not insertion order.

NumberKeyValueIterator

Iterates a plain object's entries, with the keys as numbers.

ObjectKeyValueIterator

Iterates a plain object's entries, with the key names as they are stored.

ObjectValueIterator

Iterates a plain object's values.

StringKeyMap

The JS backing of AbstractMap for String keys, and for key types that are still generic when compiled. It is a plain JS object, so JS code can read it as obj[key] and JSON.stringify it. Keys are converted with Std.string (strings are used as they are), and only the object's own properties count as entries.
