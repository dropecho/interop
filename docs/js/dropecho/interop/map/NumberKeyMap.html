abstract NumberKeyMap<K, V>(StringKeyMap<K, V>)

package dropecho.interop.map

@:forward(exists,remove,clear)

The JS backing of AbstractMap for Int and Float keys. It is a plain JS object like StringKeyMap, but keys come back as numbers when iterated. JS lists number-like keys in ascending order, not insertion order.
